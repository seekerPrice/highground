The backend and frontend lanes agree typed DTOs before coding shared consumers. Proposed minimal contract (routine implementation choices, preserve source semantics):

Comparison rows include stable baseline item identity, name/quantity, baseline estimate, condition, estimated loss, nullable evidence timestamp and uncertainty. No chat IDs, sender hashes, storage URI, agent state or other reports.
- `GET /api/report/{report_id}/media/{media_id}` and `POST /api/report/{report_id}/media/{media_id}/verify`, same capability header: enforce report membership before access. Stream/download bounded original media with known content type; verification returns integrity status and recorded hash only for this report. Browser media viewing may fetch an authorized Blob and revoke its object URL when closed; no public bucket or unscoped signed URL.
- `GET /api/dashboard`: only explicit synthetic shops, synthetic event summaries/radii, sourced destination registry, official source-status summaries, and simulation metrics with their definitions. Include response timestamp, explicit unavailable/empty status, and bounded result sizes. Missing source data is never an all-clear. Public schema must be tested against raw private records to prove field exclusion.

Do not erase real records. Task 16 owns full fixture creation/reset semantics; coordinate the minimal UI control with that later task rather than claiming reset complete early.
